# Belajar Laravel

Website belajar Laravel interaktif untuk pemula, melanjutkan seri Belajar HTML, CSS, JavaScript, dan PHP.

## Fitur

- 20 materi Laravel dari dasar dengan panduan langkah demi langkah
- Istilah penting, kesalahan umum, dan cek pemahaman pada setiap materi
- Quiz, recall challenge, dan latihan debugging
- Simulator alur route, controller, Blade, dan CSS di browser
- Ide mini project Laravel
- Progress, badge, dan tema yang tersimpan di browser

## Menjalankan

Website utama dapat dibuka sebagai situs statis. Untuk praktik Laravel asli, buat project Laravel lokal lalu jalankan:

```bash
php artisan serve
```
